# Entrepreneur Finance Dashboard

This GitHub-ready static HTML + JS dashboard consolidates multiple income streams (Airbnb, content creation, day trading) and key financial goals.

## Structure

- **index.html** → Main dashboard
- **assets/js/core/** → Core logic (data, storage, calculations, UI)
- **assets/js/modules/** → Module-specific scripts (overview, airbnb, content, trading, goals)
- **data/** → Static JSON files (can later sync with Google Sheets)
- **components/** → Reusable UI pieces
- **utils/** → Helper functions
- **assets/css/** → Global styles

## Deployment
Host free on **GitHub Pages** → Settings → Pages → Branch: `main`.

## Customization
You can expand modules, connect APIs, or add localStorage persistence via `storage.js`.
